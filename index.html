🔧 Acer Predator Helios 300 Fan Control

Linux Fan Control Guide for PH315-51

📋 Overview

This guide provides step-by-step instructions to enable manual fan control on your Acer Predator Helios 300 (PH315-51) laptop running Linux. Control your system's cooling performance with precision.

📱 Device Information

Model: Acer Predator Helios 300 PH315-51

Operating System: Linux

Tools Required: nbfc-linux, ec_sys module

⚠️ Important Warning

⚡ CAUTION: This process involves modifying kernel modules and directly writing to the embedded controller (EC). Improper configuration could damage your hardware or cause system instability. Proceed only if you understand the risks and are comfortable working at the kernel level.

🚀 Installation & Setup

Step 1: Install nbfc-linux

First, install the NBFC (Notebook FanControl) package for Linux:

yay -S nbfc-linux

Note: If you're not using Arch Linux, use your distribution's package manager (apt, dnf, etc.) to install nbfc-linux or equivalent.

Step 2: Load Kernel Modules with Write Support

Enable write support for the EC (Embedded Controller) system module:

sudo su
modprobe -r ec_sys
modprobe ec_sys write_support=1

Step 3: Configure EC Probe Values

Write the configuration values to the embedded controller:

ec_probe write 0x21 0x30
ec_probe write 0x22 0x0c
ec_probe write 0x37 0x[value]
ec_probe write 0x3a 0x[value]

Note: Replace [value] with your desired fan speed values (typically between 0x00 and 0xFF).

📊 EC Probe Values Reference

Common Register Addresses:

  • 0x21 - Primary control register
  • 0x22 - Secondary control register
  • 0x37 - Fan speed parameter 1
  • 0x3a - Fan speed parameter 2

✅ Quick Reference

All Commands in Order:

  1. Install nbfc-linux: yay -S nbfc-linux
  2. Gain root access: sudo su
  3. Unload ec_sys: modprobe -r ec_sys
  4. Reload with write support: modprobe ec_sys write_support=1
  5. Write configuration values using ec_probe commands

🛠️ Troubleshooting

Module Not Found

If ec_sys module is not available, ensure your kernel is compiled with embedded controller support. Check with your Linux distribution.

Permission Denied

Make sure you're running commands with proper sudo privileges. The ec_probe command typically requires root access.

Reverting Changes

To revert to default settings, unload the module and reload without write support:

modprobe -r ec_sys
modprobe ec_sys
